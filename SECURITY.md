# Security

Do not expose the current reference runtime to untrusted networks or use it as production monitoring infrastructure.

The Development server is loopback-only. It does not provide production authentication, authorization, tamper-evident durable storage, trusted producer identity, signing, encryption-at-rest management, or production retention controls.

Never submit reusable credentials, access tokens, passwords, cookies, private keys, API keys, raw protected content, or unnecessary personal information as telemetry attributes.

Production ingestion requires GoreeCloud Identity and Wardveil Security acceptance plus Privacy Shield controls.
