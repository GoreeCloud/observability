# Features

## Implemented in source

- Canonical nine-state operational-health vocabulary.
- Bounded operational signal validation and privacy-safe attribute checks.
- Freshness evaluation using observation timestamps and TTL.
- In-memory component-health aggregation with unknown/stale integrity semantics.
- Provenance, correlation, and collection-gap preservation.
- Local-only Development signal/health HTTP runtime.
- Standard-library unit tests and CI workflow.

## Not yet implemented or accepted

Production collectors, durable metrics/logs/traces/events storage, Identity-authenticated ingestion, Mesh transport, Manager surfaces, Policy correlation, Privacy Shield and Wardveil acceptance, Everkeep recovery, alerting, SLOs, deployment, and Stable certification remain planned or blocked.
